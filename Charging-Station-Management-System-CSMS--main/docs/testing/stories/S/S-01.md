## 1. Requirement & Acceptance Criteria

### S-01
Khung ứng dụng chạy được trên máy cá nhân của thành viên mới thông qua hướng dẫn chuẩn trong README, bảo đảm an toàn cấu hình và kết nối cơ sở dữ liệu.

#### Acceptance Criteria
- **S01-AC-01**: Given thành viên mới lấy source code, When chạy command khởi động ghi trong README (`docker compose up --build app`), Then application chạy được, database chạy được, trang chủ trả về HTTP 200.

#### Non-functional Requirements
- **S01-NFR-01**: Secrets (`JWT_SECRET`, `DATABASE_URL`) phải lấy từ environment variables, không hard-code trong mã nguồn, config hay .env.example.
- **S01-NFR-02**: Log không được in database connection string, credentials hay password.

## 2. T-01 — Dựng khung dự án và kết nối cơ sở dữ liệu

- **T01-01**: `docker compose up` -> application + database hoạt động.
- **T01-02**: Database connection -> application kết nối PostgreSQL thành công.
- **T01-03**: Migration forward -> migration chạy sạch từ 001 đến 004.
- **T01-04**: Migration rollback -> rollback thành công trên database test (`db_test`).
- **T01-05**: Naming convention schema: `snake_case`, primary key `id BIGSERIAL PRIMARY KEY`, timestamps `created_at`, `updated_at`.
- **T01-NFR-01**: Database connection string lấy từ environment (`DATABASE_URL`).
